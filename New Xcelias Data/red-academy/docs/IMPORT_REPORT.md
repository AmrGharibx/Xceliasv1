## Structure and relationship decisions

**Batch 43:** 90 actual daily records across 18 people and five dates. The attendance records explicitly name Batch 43, while the linked original trainee masters belong to Batch 42 (17) or Batch 38 (one). The originals were not moved. Supplemental Batch 43 enrollment links preserve both the recorded batch and the original person/master relationship. No earlier scores or checklists were copied into Batch 43.

**Batch 42:** 19 master roster entries, one timestamp-bearing unassigned daily record, 18 checklists and 17 assessments. The single daily record has no recorded status; it is not a presence or an absence. Blank daily shells were not turned into attendance.

**Batches 38-41:** later/changed relation names were resolved from original Notion IDs, explicit batch links and unique exact normalized names within the named batch. Twenty-one cross-linked source references were reconciled this way, with original links retained. No fuzzy name matching was used.

**Batch 30:** both genuine checklist periods remain: January 11-20 and February 1-11, 2026. Thirteen people each have two records, for 26 total. The word TEMP was not treated as sufficient evidence that these populated records were demo data.

**Shared Batch 41 assessment:** one source assessment links to 23 original trainee pages. It remains one shared assessment, not 23 individual grades, and is excluded from personal/batch graded averages. The original links and recorded 70% score are inspectable.

**Partial and historical assessments:** supplied numbers, original outcome labels, comments, reports and assessment-reported attendance/absence totals are retained. Missing skill values are NULL, not zeros. Historical duplicates remain visible; explicitly not-assessed, incomplete, shared and ambiguous duplicate results are excluded from graded averages. Source percentages are retained in the archive; app formulas use only the supplied skill inputs.

**Unknown people and times:** 16 daily records and two individual assessment records remain unassigned; the shared assessment is a separate third assessment without one trainee owner. Ninety-four source time discrepancies are preserved and flagged rather than silently corrected. Explicit GMT offsets were used for UTC conversion. Date-only time fields were not promoted to midnight check-ins.

**Checklist rollups:** some exported rollup properties contain lists of entry names rather than numeric totals. The original values remain archived as text. App totals are calculated from actual related daily statuses without coercing those lists to zero or double-counting overlapping periods.
